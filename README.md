# Meia-Noite Tycoon

Jogo de administração de cassino em 3D, feito em um único arquivo HTML com three.js.

**Jogar:** abra `index.html` no navegador ou acesse a página do GitHub Pages deste repositório.

- Seis cidades (Las Vegas, Macau, Monte Carlo, Rio de Janeiro, Atlantic City e Serra Gaúcha) com objetivos e prazos
- Quatro dificuldades, carreira e modo livre
- Milhares de variações de mesas e caça-níqueis, mais um editor de jogos com prévia 3D
- Equipe, clientes com perfis, eventos, fiscalização, marketing, empréstimos, hotel e cassinos rivais
- Tutorial, relatório diário e conquistas; funciona no computador e no celular

O progresso fica salvo no próprio navegador.
